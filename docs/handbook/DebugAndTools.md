# Debug and Tools

## Logging
- Use `DebugManager` for logs, warnings, and errors across systems.

## Debug Config
- `Resources/config/DebugConfig.asset` controls debug levels.
- `DebugManagerAutoInit` loads the config at runtime.

## Cheat Menu
- `UI/CheatMenuController.cs` provides in-game debug actions and utilities.
