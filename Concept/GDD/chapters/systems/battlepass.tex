\section{Meta Progression and Battlepass \futureflag{POST-MVP}}
\label{sec:meta-progression}

\subsection{Overview}

The Meta Progression / Battlepass System provides long-term goals across multiple sessions.
It runs in parallel to the core progression systems (Research, Heroes, Crafting, Maps) and rewards
regular play with additional resources.

This system is \textbf{not monetised} (no paid track). It is designed purely as
a long-term motivation layer and a light „quest wrapper“ around the existing gameplay.

\subsection{Design Goals}

\begin{itemize}
	\item \textbf{Structured Long-Term Goals:}
	Provide clear, mid-term targets beyond „more damage / higher difficulty“.
	\item \textbf{Soft Onboarding / Tutorial Replacement:}
	Early Battlepass objectives can guide new players through key systems
	(Maps, Research, Crafting, Heroes) instead of a rigid tutorial.
	\item \textbf{Daily / Weekly Engagement:}
	Offer small, optional tasks on a daily/weekly basis for players who enjoy checklists and routines.
	\item \textbf{Non-Essential Power:}
	Rewards support progression (materials, currencies) but must not be the only source for critical power.
\end{itemize}

\subsection{Structure}

The Meta Progression is structured as a \textbf{season-neutral} track with recurring objectives:

\begin{itemize}
	\item \textbf{Core Track (Account-Wide):}
	\begin{itemize}
		\item A linear progression bar with levels.
		\item Progress gained by completing Maps, Waves and simple objectives.
		\item Each level grants a small reward bundle.
	\end{itemize}
	\item \textbf{Objectives / Quests:}
	\begin{itemize}
		\item Simple, gameplay-aligned goals, such as:
		\begin{itemize}
			\item „Defeat X enemies on Map type Y.“
			\item „Complete N Waves without losing a Hero.“
			\item „Craft or upgrade an item.“
		\end{itemize}
		\item Objectives exist in three scopes:
		\begin{itemize}
			\item \textbf{Intro Objectives:} early, tutorial-like tasks introducing core systems.
			\item \textbf{Daily Objectives:} small tasks meant to be completed in a short session.
			\item \textbf{Weekly Objectives:} slightly larger goals for regular players.
		\end{itemize}
		\item Completing objectives grants Battlepass XP (progress on the core track) and sometimes direct rewards.
	\end{itemize}
\end{itemize}

\subsection{Rewards}

Battlepass rewards should be „nice to have“, not mandatory:

\begin{itemize}
	\item \textbf{Primary Rewards (Economy-Oriented):}
	\begin{itemize}
		\item rare Materials (higher-tier Remains, special crafting reagents),
		\item rare Currencies,
		\item Gold bundles.
	\end{itemize}
	\item \textbf{Secondary Rewards (Future / Optional):}
	\begin{itemize}
		\item cosmetic variations (skins, visual effects),
		\item cosmetic Hideout decorations or UI themes.
	\end{itemize}
\end{itemize}

The Battlepass must not be the only reliable source for:
\begin{itemize}
	\item key unlocks (Maps, Heroes, basic crafting),
	\item core power spikes (Gear tiers, base stat growth).
\end{itemize}

It is an \emph{accelerator} and a „reward wrapper“ around what the player already does, not a mandatory grind path.

\subsection{Interaction with Other Systems}

\begin{itemize}
	\item \textbf{Research System:}
	\begin{itemize}
		\item Objectives can reference Research milestones (e.g. „Start a new research project“, „Complete X kills for research“),
		\item but Research unlocks remain independent from Battlepass progression.
	\end{itemize}
	\item \textbf{Map System:}
	\begin{itemize}
		\item Many objectives are Map/Wave based (kills, completions, difficulty tiers).
		\item Map variety (themes, enemy families) can be reflected in specific objectives.
	\end{itemize}
	\item \textbf{Crafting and Inventory:}
	\begin{itemize}
		\item Objectives can reward and require basic crafting actions (craft an item, infuse gear),
		\item Reward bundles contain Materials and currencies that directly feed into crafting.
	\end{itemize}
\end{itemize}

\subsection{Minimal Scope}

For MVP, the Battlepass / Meta Progression should remain simple:

\begin{itemize}
	\item \textbf{Single Core Track:}
	\begin{itemize}
		\item one account-wide bar with a limited number of levels,
		\item no seasonal reset logic required initially.
	\end{itemize}
	\item \textbf{Basic Objective Sets:}
	\begin{itemize}
		\item a small set of Intro Objectives that guide the player through:
		\begin{itemize}
			\item playing Maps,
			\item using the MapDevice,
			\item starting Research,
			\item crafting basic gear,
			\item equipping Heroes.
		\end{itemize}
		\item a limited pool of Daily/Weekly objectives rotating randomly.
	\end{itemize}
	\item \textbf{Reward Types:}
	\begin{itemize}
		\item bundles of Gold,
		\item mid-tier Materials,
		\item small amounts of rare Currencies.
	\end{itemize}
\end{itemize}

Further extensions (cosmetics, advanced objective chains, seasonal structure) can be added once core progression and economy are stable.
